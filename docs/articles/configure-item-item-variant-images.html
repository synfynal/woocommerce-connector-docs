    Configure an item and item variant images

    The WooCommerce Connector provides the capability to configure item and item variant images. After you have configured item and item variant images, you can use the image synchronization feature to upload the images from Business Central to WooCommerce product galleries.

    To configure an item image

    1. Select Search (Alt+Q) , enter woocommerce connector setup, and then choose the related link.

      The WooCommerce Connector Setup page opens.

    2. On the action bar, choose Data > Webstore Item Mapping.

      The Webstore Item Mapping page opens.

    3. Select the item for which you want to configure an image, and then on the action bar, choose Manage > Edit.

      The Item Card page opens.

    4. In the Details FactBox pane, select Picture > Import.

      The Select a picture to upload dialog box opens.

    5. To upload an image, drag a file into the dialog box or select the link to browse to the file.

      The image is uploaded.

    To configure an item variant image

    1. Select Search (Alt+Q) , enter woocommerce connector setup, and then choose the related link.

      The WooCommerce Connector Setup page opens.

    2. On the action bar, choose Data > Webstore Item Mapping.

      The Webstore Item Mapping page opens.

    3. Select the item for which you want to configure an image, and then on the action bar, choose Item > Variants.

      The Webstore Item Variant Mapping page opens.

    4. Select the item variant for which you want to configure an image, and then in the Details FactBox pane, select Picture > Import.

      The Select a picture to upload dialog box opens.

    5. To upload an image, drag a file into the dialog box or select the link to browse to the file.

      The image is uploaded.
