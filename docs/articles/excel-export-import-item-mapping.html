    Excel export and import for item mapping

    The WooCommerce Connector can export the items on the Webstore Item Mapping page to an Excel workbook and import the workbook back into Business Central. Use the Excel export and import feature to update many items at once, map many items to WooCommerce products, or move item mapping from one webstore to another.

    When you import a workbook, the WooCommerce Connector shows a preview of every change and every problem before it writes anything. You review the preview, clear the rows that you do not want to import, and then import the rest.

    Export items to Excel

    When you export items, the WooCommerce Connector creates a workbook that contains one row for each item and one column for each field that you select. You can filter the items to export and choose the columns to include.

    To export items to Excel

    1. Select Search (Alt+Q) , enter woocommerce connector setup, and then select the related link.

      The WooCommerce Connector Setup page opens.

    2. If multiple setups exist, select the setup that you want to configure, and then on the action bar, select Manage > View.

      The WooCommerce Connector Setup page opens.

    3. On the action bar, select Data > Webstore Item Mapping.

      The Webstore Item Mapping page opens.

    4. On the action bar, select Excel > Export to Excel.

      The Export Items to Excel page opens.

    5. In Webstore Code, select the webstore whose item mapping you want to export.

      The webstore columns in the workbook, such as Webstore ID, belong to this webstore.

    6. (Optional) To change the fields that the WooCommerce Connector writes to the workbook, in Columns, select the assist edit button, and then select the columns to export.

      To learn how to select columns, see the following section.

    7. (Optional) In the Filters section, specify which items to export:

      1. In Item No. Filter, specify the item numbers to export. For example, enter WB* to export items with numbers that begin with WB.

      2. In Item Category Filter, specify the item categories to export.

      3. Turn on Mapped Items Only to export only mapped items. When Mapped Items Only is turned off, the export includes all items that match the other filters.

      4. Turn on Exclude Blocked Items to leave blocked items out of the export. When Exclude Blocked Items is turned off, the export includes blocked items that match the other filters.

    8. Select OK.

      The WooCommerce Connector exports the items to an Excel workbook.

    Select the columns to export

    The Columns field on the Export Items to Excel page summarizes the fields that the workbook includes. The Select Columns page opens on a short list of the fields that most exports need. By default, the following fields are selected: No., Description, Manage Stock on Webstore, Webstore ID, and Use in Webstore.

    The Select Columns page includes the following columns:

    • Include: Specifies whether the field is written to the workbook.
    • Field Caption: The name of the field.
    • Source: Where the field comes from, such as Item or Item Webstore Connector.
    • Export Only: Indicates that the field is written to the workbook but ignored when you import the workbook.

    Key fields are always included in the workbook.

    To select the columns to export

    1. On the Export Items to Excel page, in Columns, select the assist edit button.

      The Select Columns page opens.

    2. To see every field that you can export, on the action bar, select Show All Fields.

    3. For each field that you want to include, select the Include checkbox.

    4. (Optional) To select or clear all fields at once, on the action bar, select Select All or Deselect All.

    5. (Optional) To return to the default selection of fields, on the action bar, select Restore Defaults.

    6. Select Close.

    What the workbook contains

    The workbook contains the following sheets:

    • Item: One row for each exported item, with a header row that contains the field captions. Fields that are checkboxes in Business Central appear as Yes or No. The Use in Webstore column corresponds to the Webstore Item checkbox on the Webstore Item Mapping page.
    • Instructions: A summary of how to import the workbook. The import reads the Item sheet and ignores the Instructions sheet.

    Edit the workbook

    Use the following rules when you edit the workbook:

    • A blank cell clears the value of the field. To keep the current values of a field, delete its column from the workbook instead of emptying the cells.
    • A row with a blank No. creates a new item. A row with a No. that does not exist yet creates a new item with that number.
    • A blank or 0 value in Webstore ID means that the item is not mapped to a webstore product. When you clear Webstore ID, the import unmaps the item from its product. If Webstore ID contains an ID that does not match a product in the webstore, the preview shows an error for the row.
    • Columns marked as Export Only on the Select Columns page are ignored when you import the workbook.
    • Import the workbook in the language that it was exported in. The column headers are field names in that language.

    Import from Excel

    When you import a workbook, the WooCommerce Connector first opens a preview that lists every row and every problem that it found. Nothing is written to Business Central until you select Import in the preview.

    To import items from Excel

    1. Select Search (Alt+Q) , enter woocommerce connector setup, and then select the related link.

      The WooCommerce Connector Setup page opens.

    2. If multiple setups exist, select the setup that you want to configure, and then on the action bar, select Manage > View.

      The WooCommerce Connector Setup page opens.

    3. On the action bar, select Data > Webstore Item Mapping.

      The Webstore Item Mapping page opens.

    4. On the action bar, select Excel > Import from Excel, and then select the workbook that you want to import.

      The Excel Import Preview page opens.

    5. Review the preview. To learn how to read the preview, see the following section.

    6. Clear the checkbox for each row that you do not want to import.

    7. On the action bar, select Import.

      The WooCommerce Connector writes the selected rows to Business Central, and a message shows how many items were created and updated.

    Review the import preview

    The top of the Excel Import Preview page shows the following counts: Rows to Create, Rows to Update, Unchanged Rows, Rows with Errors, Selected Rows, and Unknown Columns. Select a count to filter the list to those rows. The Showing field shows which rows are listed. By default, the list shows rows that have changes and rows that have errors. To change which rows are listed, on the View tab, select Show Changes and Errors or Show All Rows.

    For each row, the list shows the following information:

    • Worksheet Row: The row number in the workbook.
    • No. and Description: The item that the row belongs to.
    • Action: Whether the import creates the item (Create), updates the item (Update), or cannot import the row (Error).
    • Changes: The number of fields that the import changes.
    • Warning: A warning about the row. A row with a warning can still be imported.

    A row with an error cannot be selected. For example, if a numeric column contains text, the row shows an error such as thirty-nine is not a valid Decimal. If Webstore ID contains an ID that does not exist in the webstore, the row shows an error such as Webstore MAIN has no product with ID 5000. Correct the Webstore ID in the workbook. The Row Values FactBox shows the new values of the selected row and marks the value that causes the error in red.

    To compare the current value and the new value of every field in a row, select the row, and then on the View tab, select Show Changes. The Excel Import Values page opens and lists each field with its current value and new value. The new value of a field that changes appears in bold, and the Changed checkbox is selected for that field. If a value causes an error, the Error Message column shows the reason.

    To check the rows again, on the Home tab, select Validate Again. To select or clear all rows at once, select Select All or Deselect All.

    Import results

    The WooCommerce Connector writes each selected row separately. If one row cannot be written, the other rows are still imported.

    When all selected rows are imported, a message shows how many items were created and updated. For example: The import is finished: 1 created and 2 updated.

    When a row fails while it is written, the message includes the number of rows that were not imported because of an error, and the Excel Import Preview page shows the results. The page shows the number of created records, updated records, failed rows, and skipped rows. Skipped Rows includes rows that have no changes and rows that you cleared in the preview. The Result column shows the result of each row, such as Updated, Failed, or Skipped. The Error Message column shows the reason that a row failed, including the field and the workbook cell. For example: Base Unit of Measure (C18): You cannot change Base Unit of Measure because there are one or more open ledger entries for this item.

    Rows that were not imported stay in the list with the reason. To correct the problem, edit the workbook, and then import it again.

    Use Excel export and import with product variations as items

    When Item Variations as Items is turned on, the Select Columns page includes the Webstore Parent ID field. By default, Webstore Parent ID is not included in the workbook. To include it, on the Select Columns page, select the Include checkbox for Webstore Parent ID.

    If Skip Parent Item Creation is turned on, the WooCommerce Connector populates Webstore Parent ID automatically during synchronization. If you change Webstore Parent ID in the workbook, the import checks that the item's Webstore ID is a variation of the parent product. If it is not, the preview shows an error for the row, such as Webstore ID (E7): Webstore ID 1035 is not a variation of webstore product 123.

    Import item mapping into a different webstore

    The webstore columns in a workbook, such as Webstore ID, belong to the webstore that you selected when you exported the workbook. To import them into a different webstore, for example to move item mapping from a sandbox into production, in the Excel Import Preview page, in Webstore Code, select the webstore that you want to import into. The WooCommerce Connector checks every row again for the selected webstore.
