    Manage failed push attempts

    The WooCommerce Connector can place records on hold when scheduled synchronization repeatedly fails with the same error.

    A record that is placed on hold is not a connector error. This status indicates that Business Central and the webstore have diverged for the record and that the data might need to be corrected. To learn more about the reason for the failure, review Last Sync. Error for the record.

    Configure the maximum number of push attempts

    The Max. No. of Attempts to Push setting determines how many consecutive scheduled push attempts can fail with the same error before the WooCommerce Connector places a record on hold.

    The setting applies separately to each webstore. The default value is 3. A value of 0 prevents the WooCommerce Connector from placing records on hold.

    To configure the maximum number of push attempts

    1. Select Search (Alt+Q) , enter woocommerce connector setup, and then select the related link.

      The WooCommerce Connector Setup page opens.

    2. If multiple setups exist, select the setup that you want to configure, and then on the action bar, select Manage > Edit.

    3. On the General FastTab, in the Synchronization section, in Max. No. of Attempts to Push, enter the maximum number of consecutive failed push attempts.

      Enter 0 to prevent records from being placed on hold.

    Note

    Note:
    Existing webstore setups are assigned a value of 3 when the WooCommerce Connector is upgraded. To continue using unlimited push attempts, set Max. No. of Attempts to Push to 0.

    How records are placed on hold

    During a scheduled synchronization, the WooCommerce Connector tracks consecutive push failures for each record.

    The WooCommerce Connector applies the following rules to failed pushes:

    • A push that fails with the same error as the previous attempt increases No. of Failed Push Attempts by one.
    • When No. of Failed Push Attempts reaches Max. No. of Attempts to Push, the WooCommerce Connector selects the Push On Hold checkbox.
    • A push that fails with a different error resets No. of Failed Push Attempts to 1.
    • A record with Push On Hold selected is not attempted during subsequent scheduled synchronization runs.

    For example, when Max. No. of Attempts to Push is set to 3, a record must fail with the same error on three consecutive scheduled runs before the WooCommerce Connector places the record on hold.

    Records affected by push holds

    The push hold feature applies to records that the WooCommerce Connector synchronizes from Business Central to the webstore.

    The feature applies to the following records:

    • Items
    • Item variants
    • Item categories
    • Item attributes
    • Item attribute values
    • Customers
    • Coupons

    The feature does not apply to sales orders. Synchronizing sales orders from the webstore to Business Central is unaffected, and pushing order updates back to the webstore is not currently covered by push holds.

    View records on hold

    The Push On Hold and No. of Failed Push Attempts fields show the push status for each record on the Webstore Connectors pages.

    The following Webstore Connectors pages show these fields:

    • Item Webstore Connectors
    • Item Variant Webstore Connectors
    • Item Category Webstore Connectors
    • Item Attribute Webstore Connectors
    • Item Attribute Value Webstore Connectors
    • Customer Webstore Connectors
    • Coupon Webstore Connectors

    The Push On Hold field is also available on the following pages:

    • Webstore Item Mapping
    • Webstore Customer Mapping
    • Webstore Item Variant Mapping
    • Webstore Item Category Mapping
    • Webstore Item Attribute Mapping
    • Webstore Item Attribute Value Mapping
    • Coupons

    To identify the reason for a push failure, review Last Sync. Error for the record.

    Manual synchronization

    Manual synchronization is not blocked by a push hold.

    When you manually synchronize a record, the WooCommerce Connector pushes the record even when Push On Hold is selected.

    The following manual actions can push a record that is on hold:

    • Synchronize
    • Synchronize Selected
    • Push actions on the item, item variant, item category, item attribute, customer, and coupon pages

    A failed manual push updates Last Sync. Error, but does not change No. of Failed Push Attempts or Push On Hold.

    Release a push hold

    You can release a push hold by manually synchronizing the record or by clearing the Push On Hold checkbox.

    A successful synchronization clears the push hold and resets No. of Failed Push Attempts to 0.

    After a successful manual synchronization, the record can be processed normally during the next scheduled synchronization run.

    To manually release a push hold

    1. Open the applicable Webstore Connectors page.

    2. Locate the record with Push On Hold selected.

    3. Clear Push On Hold.

      The WooCommerce Connector resets No. of Failed Push Attempts to 0.

    Scheduled synchronization of records on hold

    During a scheduled synchronization run, the WooCommerce Connector skips records that have Push On Hold selected.

    When a record is skipped, the WooCommerce Connector does not update the record's synchronization information or create a failed Activity Log entry for the skipped record.

    A push hold applies to a record for a specific webstore. The same record can continue to synchronize with other webstores where the record is not on hold.

    A push hold affects push synchronization only. Pull synchronization can still update a record that is on hold.
