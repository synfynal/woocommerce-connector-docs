    Item attributes

    The attribute synchronization feature provides the capability to seamlessly transfer product attributes and their values between WooCommerce and Business Central. The synchronization ensures that product characteristics, such as size, color, and material, along with their values remain consistent across both platforms. Keeping attributes and values aligned enables businesses to manage product variations more efficiently, improve product organization, and deliver a consistent customer experience. This integration updates data automatically in both directions, eliminating manual entry and ensuring accurate product information across platforms.

    Key details

    • The WooCommerce Connector synchronizes attributes such as size, color, material, which users define in WooCommerce or Business Central.

    • The WooCommerce Connector synchronizes attribute values such as small, red, and cotton, which define the specific options for each attribute.

    • The integration uses these synchronized attributes and values to create product variations, which both systems display accurately for effective product management.

    • The synchronization ensures that any change that a user makes in one platform is reflected in the other, which eliminates the need for manual entry and reduces the risk of data discrepancies.

    Note

    Note:
    In WooCommerce, attribute information is configured in two places. One location is under Products > Attributes, and the other is on the Attributes tab within each product. Attribute values are configured only in the second location. The WooCommerce Connector synchronizes data between Business Central and both locations.
