# Compatibility and supported versions

Learn about the system requirements and supported versions for the WooCommerce Connector. It is recommended that you review these requirements before installation or upgrading to avoid compatibility issues.

## Microsoft Dynamics 365 Business Central support

The following sections include information about Microsoft Dynamics 365 Business Central support.

### Supported editions

The WooCommerce Connector is compatible with the Essential and Premium editions of Microsoft Dynamics 365 Business Central.

### Supported versions

The WooCommerce Connector is compatible with the latest version of Business Central, both for on-premises (On-Prem) and cloud deployments.

## WooCommerce

The WooCommerce Connector supports WooCommerce 3.5 or later.

### WooCommerce composite products

The WooCommerce Connector does not support the synchronization of WooCommerce composite products because these products are not a standard WooCommerce option.

## WordPress

The WooCommerce Connector supports WordPress 4.4 or later.

## Microsoft Dynamics NAV

The WooCommerce Connector is not supported with Microsoft Dynamics NAV.
