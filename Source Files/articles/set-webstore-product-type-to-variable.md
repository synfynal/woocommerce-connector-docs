# Set the webstore product type to variable

When configuring item variants, the first step is to set the webstore <b>Product Type</b> to <i>Variable</i> on the <b>Item Card</b> page.

## To set the webstore product type to variable

1. Choose ![Lightbulb that opens the Tell Me feature.](media/ui-search/search_small.png "Tell me what you want to do"), enter <i>items</i>, and then choose the related link.

   The <b>Items</b> page opens.

1. Select the item for which you want to configure item variants, and then on the action bar, choose <b>Manage</b> > <b>Edit</b>.

   The <b>Item Card</b> page opens.

1. On the <b>Webstore</b> FastTab, in <b>Product Type</b>, specify <i>Variable</i>.
