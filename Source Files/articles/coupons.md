# Coupons

During order synchronization, the WooCommerce Connector applies coupons from webstore orders to the respective sales orders in Business Central. 

To learn more about coupon functionality in the WooCommerce Connector, select the links in the following table.

| To | Go to |
|---|---|
| Learn about pushing coupon data from Business Central into your webstore. | [Push coupon data to the webstore](push-webstore-coupons.md) | 
| Learn about pulling coupon data from your webstore into Business Central. | [Pull coupon data from the webstore](pull-webstore-coupons.md) |
| Learn about the pull synchronization start date for coupons. | [Pull synchronization start date for coupons](pull-synchronization-start-date-for-coupons.md) |
| Learn how to configure the number series that you want to use to assign numbers to coupons. | [Coupon numbers](coupon-numbers.md) |
